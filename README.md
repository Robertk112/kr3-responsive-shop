# RoastLab

## О проекте

RoastLab — многостраничный интернет-магазин кофе и оборудования для домашнего заваривания. Проект выполнен в рамках контрольной работы №3 по дисциплине «Фронтенд и бэкенд разработка».

**Автор:** Кирштейн Роберт, ЭФБО-07-25. [Репозиторий КР №3](https://github.com/Robertk112/kr3-responsive-shop)

## Страницы сайта

- `index.html` — главная с популярными товарами, отзывами, FAQ и картой магазинов в Москве.
- `catalog.html` — каталог с поиском, фильтрами, сортировкой и сравнением.
- `category-coffee.html` — раздел кофе в зёрнах.
- `product.html` — карточка «Бразилия Серрадо» с галереей, характеристиками и расчётом стоимости.
- `order.html` — форма заявки на товар.
- `contacts.html` — адреса магазинов, график работы и форма обратной связи.
- `account.html` — регистрация, вход, профиль и избранное.
- `cart.html` — товары в корзине, количество, итоговая сумма и оформление заявки.

## Структура проекта

- `css/style.css` — шапка, навигация, карточки, формы, модальные окна и подвал.
- `css/responsive.css` — медиазапросы и раскладка для телефонов, планшетов и компьютеров.
- `js/main.js` — мобильное меню, галерея, калькулятор и обработка форм.
- `frontend/` — React-компоненты каталога, личного кабинета и корзины.
- `js/catalog.bundle.js` — готовая сборка React-компонентов.
- `api/products.json` — данные 18 товаров.
- `server.go`, `accounts.go` — сервер, API каталога, обратная связь и учётные записи.
- `images/` — фотографии товаров и их варианты для разных экранов.
- `lighthouse/` — сохранённые отчёты по доступности.

## Используемые технологии

- HTML5 и CSS3, Flexbox и CSS Grid.
- JavaScript и React.
- Go и JSON API.
- `localStorage` для корзины и избранного.
- Git и GitHub.

Для оформления используются собственные стили без Bootstrap.

## Реализовано

- Адаптивная навигация, хлебные крошки и единый подвал на страницах сайта.
- Поиск по каталогу, сортировка, фильтры по категориям и цене, сравнение до трёх товаров.
- Галерея, характеристики и калькулятор стоимости от 1 до 12 упаковок с переносом расчёта в заявку.
- Модальное окно заявки с проверкой полей. При открытии из корзины в нём отображаются товары, количество и итог.
- Карта Яндекса на главной, адреса и график работы магазинов, отправка обращения со страницы контактов.

### Элементы для КР №4

- **Регистрация и авторизация.** При регистрации обязательны имя, e-mail, телефон, пароль и согласие на обработку персональных данных. Сервер проверяет данные и хранит хеш пароля. Вход по e-mail и паролю сохраняется между страницами через сессионную cookie.
- **Личный кабинет.** До входа отображается форма авторизации и регистрации. После входа доступны данные профиля, избранные товары, переход в корзину со счётчиком и выход из аккаунта.
- **Корзина с подсчётом суммы.** Товары можно добавить из каталога, карточки товара и избранного. При изменении количества пересчитываются сумма позиции и общий итог. Можно удалить отдельный товар, очистить корзину и отменить очистку до обновления страницы.
- **Избранные товары.** При нажатии на сердечко каталог проверяет вход. Гостю открывается окно авторизации. После входа или регистрации выбранный товар добавляется автоматически. В профиле товар можно убрать из списка или перенести в корзину.

## Запуск

В корне проекта запустите сервер через Go 1.25 или новее.

```sh
go run .
```

Если Go лежит в локальной папке `.tools`, используйте команду для PowerShell.

```powershell
.\.tools\go\bin\go.exe run .
```

Откройте [локальную главную страницу](http://127.0.0.1:8080/).

При открытии [index.html](index.html) с диска доступны витрина, каталог из встроенного снимка данных, сравнение, калькулятор и корзина. Регистрация, вход, избранное и отправка обратной связи требуют запущенного Go-сервера. Для карты Яндекса нужен интернет.

После изменения React-компонентов или данных каталога пересоберите клиентскую часть.

```sh
pnpm install --frozen-lockfile
pnpm run build
```

## Хранение данных и формы

Корзина и избранное сохраняются в `localStorage` для текущего браузера и адреса сайта. Сервер хранит учётные записи и хеши паролей в `.roastlab/accounts.json`. Обращения с контактной формы сохраняются в `.roastlab/feedback/`, ответы отправляются вручную. Форма заявки на товар проверяет введённые данные в браузере.

## Доступность и адаптивность

- **Практика №12.** Используется Mobile First. Адаптивные стили подключены на всех восьми страницах. Для изображений используются `srcset`, `sizes` и `picture`. На узких экранах таблица характеристик заменяется списком «параметр — значение».
- **Практика №13.** На страницах есть ссылка пропуска к содержимому и видимый фокус. Поля связаны с подписями и сообщениями об ошибках. Изображения имеют `alt`, диалоги — доступные заголовки.
- **Практика №14.** В Edge проверены восемь страниц при ширинах **360, 430, 768, 1024 и 1440 px**. В проверенных состояниях горизонтальной прокрутки не было. Проверены открытие окна заявки и возврат фокуса после закрытия.

В папке `lighthouse/` сохранены отчёты по доступности за предыдущую публикацию в репозитории КР №1. Главная, каталог и заявка получили **100/100**. Для оценки текущей версии нужен новый прогон Lighthouse. Полный ручной проход по Tab на всех страницах отдельно не подтверждён.
